##Sobre o Projeto

Este projeto foi desenvolvido para a Global Solution FIAP 2026 e propõe uma plataforma web para gestão inteligente de recursos em uma colônia lunar.

A solução permite monitorar em tempo real indicadores essenciais como energia, água, oxigênio e produção de alimentos, auxiliando na tomada de decisões e na sustentabilidade da operação. O sistema prioriza usabilidade, clareza visual e organização das informações por meio de dashboards e alertas inteligentes.

Embora inspirado no contexto espacial, o projeto também pode ser aplicado a desafios reais na Terra, como cidades inteligentes, monitoramento ambiental, gestão de recursos e situações de emergência.

O desenvolvimento está alinhado aos Objetivos de Desenvolvimento Sustentável (ODS), promovendo inovação, sustentabilidade e uso eficiente de recursos.
