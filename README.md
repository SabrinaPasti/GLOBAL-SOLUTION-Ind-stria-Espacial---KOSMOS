# GLOBAL-SOLUTION-Ind-stria-Espacial---KOSMOS
Plataforma web para gestão de recursos em uma colônia lunar, permitindo monitorar energia, água, oxigênio e produção de alimentos em tempo real. A solução utiliza dashboards e alertas inteligentes para apoiar a tomada de decisões, promovendo eficiência operacional, inovação e sustentabilidade.
